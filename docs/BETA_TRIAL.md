# Beta Trial

本文件用于组织公开试用前的 30 分钟本机体验检查。试用记录应只保存必要结论，不保存用户源码正文、prompt/response 正文、API key、token 或完整隐私路径。

## 试用目标

- 能打开本地项目并浏览文件。
- 能用 Agent 生成计划、补丁草案和验证建议。
- 能看到质量门、命令输出摘要和剩余风险。
- 能在 Accept、Rework、Reject、Rollback 等决策之间切换。
- 能确认高风险命令和文件写入不会静默发生。

## 试用流程

1. 用一个可公开或临时测试项目启动 Codek。
2. 提交一个小型真实任务，例如修复测试、补一段文档或调整一个组件状态。
3. 检查 Agent 是否给出计划、diff、验证命令和风险说明。
4. 运行建议的测试或 typecheck。
5. 记录任务是否完成、失败原因、回滚建议和用户是否愿意继续试用。

## 记录要求

可以记录：

- Codek 版本或 commit。
- 操作系统和启动方式。
- 任务类型和最终结果。
- 验证命令是否通过。
- 用户反馈摘要。

不要记录：

- 用户私有源码正文。
- prompt/response 全文。
- API key、Bearer token、SSH key、证书、私钥。
- 本机完整用户目录、临时目录或 `.codek` 报告原文。
